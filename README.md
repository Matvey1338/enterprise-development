## Реализация

Модель описывает клиентов химчистки, принятые изделия, категории изделий и заказы. Данные хранятся в коллекциях в памяти. Пять запросов из задания реализованы с помощью LINQ и проверяются модульными тестами xUnit.

На данном этапе база данных MySQL и брокер сообщений NATS не используются, так как лабораторная работа № 1 посвящена созданию объектной модели и обработке данных в памяти.

| Тип | Назначение |
|---|---|
| `Category` | Справочник категорий изделий: название, рекомендуемый вид чистки и стоимость чистки |
| `Item` | Принятое изделие: наименование, материал и ссылка на категорию |
| `Client` | Клиент химчистки: ФИО и телефон |
| `Order` | Заказ: клиент, изделие, дата приёма, срок выполнения в днях и статус |
| `OrderStatus` | Статус заказа: принят, в обработке, выполнен, выдан, отменён |
| `CleaningType` | Вид чистки: сухая, аквачистка, влажная, для кожаных и меховых изделий |

Каждому заказу соответствует ровно одно принятое изделие; заказ хранит ссылки на клиента и изделие. Категория является справочником: изделие содержит ссылку на его элемент, а стоимость чистки определяется категорией изделия. Статус заказа представлен перечислением `OrderStatus`.

Обязательные ссылочные свойства помечены `required`. Публичные классы, свойства и перечисления снабжены XML-комментариями.

## Модульные тесты

Тестовые данные готовятся в фикстуре `DryCleaningFixture`: 10 категорий, 12 клиентов, 28 заказов и 28 изделий — не менее 10 экземпляров каждого класса. Даты приёма заказов вычисляются относительно даты, зафиксированной при создании фикстуры, поэтому результаты тестов не зависят от дня их запуска. Каждый запрос покрыт отдельным тестовым классом:

| Запрос | Тестовый класс |
|---|---|
| Заказы, находящиеся в обработке, упорядоченные по дате приёма | `OrdersInProcessingTests` |
| Топ-5 клиентов, сдавших больше всего изделий за заданный период | `TopClientsByItemsInPeriodTests` |
| Клиенты, чьи заказы обрабатывались дольше всего, упорядоченные по ФИО | `ClientsWithLongestProcessingTests` |
| Топ-5 наиболее и наименее популярных категорий изделий за последний год | `CategoryPopularityTests` |
| Клиент, потративший наибольшую сумму за весь период работы химчистки | `TopSpenderClientTests` |

Принятые допущения:

- длительность обработки заказа определяется его сроком выполнения (`CompletionTermDays`), так как фактическая дата завершения в предметной области не хранится;
- категории без заказов за последний год считаются наименее популярными (0 заказов);
- отменённые заказы не оплачиваются и не учитываются в сумме трат клиентов.
